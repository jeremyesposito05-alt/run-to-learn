# Run to Learn!

Jeu de course éducatif (maths, français, anglais, allemand) pour le Collège Alpin Beau Soleil.
Attrape les bonus question, réponds juste pour garder ton endurance, traverse les biomes.

Jouer : https://jeremyesposito05-alt.github.io/run-to-learn/

Tout fonctionne dans le navigateur, sans serveur ; la progression reste sur l'appareil.
Moteur et habillage provisoire : l'habillage « Donkey Kong Country » viendra remplacer `js/render.js`.
